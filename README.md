# 🛡️ AI Vision DefectGuard
> **Low-Cost Automated Quality Control System for MSMEs using YOLOv8 & Computer Vision**

## 📌 Problem Statement
Small and Medium Enterprises (MSMEs) struggle with high defect rates due to manual quality inspection. Industrial vision systems are extremely expensive ($5000+).

## 🚀 Solution
**AI Vision DefectGuard** converts any standard webcam or smartphone camera into an AI-powered automated quality checker with ZERO hardware installation costs.

## ✨ Key Features
- **Real-Time Visual Defect & Object Detection** powered by YOLOv8 Neural Network.
- **Dynamic Analytics Dashboard** with instant Pass/Fail ratio metrics.
- **Zero Hardware Requirement** — Works on existing laptops, webcams, or IP cameras.

## 🛠️ Tech Stack
- **AI/CV:** Python, OpenCV, Ultralytics YOLOv8
- **Frontend/Dashboard:** Streamlit, Plotly, Pandas
